The entry line (129 characters, one line):

## Run it

```sh
python3 main.py
```

## Why this line

It roasts the agent itself, not chatbots in general: twelve tool calls that go nowhere, a confident answer to a question nobody asked, and the agent's favourite parting tic — offering the wrong answer as a table. The twist lands on the last word.
